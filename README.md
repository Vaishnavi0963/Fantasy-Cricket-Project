# Fantasy Cricket Game

A Fantasy Cricket game developed using Python, Tkinter, and SQLite, featuring team selection, player trading, points calculation, and a leaderboard.

## Features

- *Team Selection*: Build your fantasy cricket team within a budget.
- *Player Trading*: Trade players between teams.
- *Points System*: Points are awarded based on real player performances.
- *Leaderboard*: View your rank and compare with other players.
- *GUI*: Designed a user-friendly interface with Tkinter.
- *Database*: Managed player data, teams, and contests with SQLite.

## Tech Stack

- *Python*
- *Tkinter* (GUI)
- *SQLite* (Database)

## Installation

1. Clone the repository:
   
   git clone https://github.com/yourusername/fantasy-cricket-game.git
   cd fantasy-cricket-game

2. Install dependencies:

pip install -r requirements.txt


3. Run the app:

python main.py


How to Play

1. Register and log in.

2. Select your team within the budget.

3. Trade players as per the game rules.

4. Track live scores and see the leaderboard.
